## Entry Sequencing [DERIVED]

1. **T1 (TAGIS recertification, Taraba) — first overall:** only opportunity where revenue event and transaction gateway are both legislated, with a published front door.
2. **T2 (TSIRS expansion) in parallel** — establishes the Revenue Core reference configuration.
3. **O1 (Ogun quarry e-ticketing)** — publicly documented leakage + standing PPP Office [LIVE].
4. **S1 + S3 (Osun)** — reform momentum in an election year; signatures before Q4 2026 hardening.
5. **N2/N3/N5 (Nasarawa) on the T1 reference** — most professional counterparty; directive pre-authorizes structure [LIVE].
6. **B1 (Benue)** — largest single revenue pool, most stakeholder work; enter with four-state references.
7. **Lagos (L4 → L1/L2)** — LAWMA collection integrity first, then premium plays; last to sign, first in reference value.
8. **Security-gated / 12–24-month items** (B2, T3, T4, B4, O4/O5, L5) — pilot in secure windows; scale with posture and asset timelines.

## Shared Platform Economics

One Meridian core, six state-configured deployments [DERIVED]. The TAGIS build establishes the land configuration reused by N2/B3/S3/O2 at marginal cost; TSIRS expansion establishes the collections configuration reused in B1/O3/S1/N3/N5/L4; O1/N1/T3/S2 share the extractives configuration; L1/S5 share the security configuration. Bid economics improve monotonically — each subsequent state carries lower build cost and shorter time-to-revenue. **Pricing discipline:** never price below the marginal-configuration cost floor just to win a flagship.

**Design target: 80/20** — ≥80% shared configuration, ≤20% per-state customization; anything past 20% is a product-management escalation [DERIVED policy].
