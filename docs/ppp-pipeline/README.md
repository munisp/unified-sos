## The Spectrum Thesis

From ₦17.46bn (Taraba) to ₦1.26trn (Lagos) of IGR [LIVE] — from "first e-payment ever" to "Africa's most sophisticated revenue service" — is exactly what makes a reusable State Operating System viable. The same seven modules appear in all six states; only configuration depth and lead module change. Taraba's TSIRS doubling [LIVE] proves the basic tier; Osun's +97.3% in two years [LIVE] proves the deepening tier; Lagos's LSSTF/LIRS [LIVE] are the premium-tier governance templates.

**None of these engagements requires state capex.** Vendor-financed, revenue-share structures convert informal cash flows or under-automated formal flows into bankable, shared revenue — every state has a legal PPP path [LIVE]: NASIDA, TARIPA, BIPC/BDIC, Ogun's 2019 PPP Law + standing PPP Office, Osun's user-fee-concession law, Lagos's mature concession practice.
