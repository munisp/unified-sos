# 90-Day Execution Playbook for State Leadership

## Days 1–30: Executive Alignment & Legal Gazetting

1. State Executive Council (SEC) approves the SOS Turnkey PPP Concession Agreement.
2. Ministry of Finance gazettes the automated TigerBeetle TSA statutory split formula.
3. Form the State Implementation Committee (Finance, Internal Revenue, Lands, Justice, Concessionaire).

## Days 31–60: Sovereign Cloud Setup & IAM Realm Federation

1. Provision the state Kubernetes namespace / dedicated VPC in a Tier-3 Nigerian data center.
2. Configure the State Keycloak Realm and federate with the NIMC NIN database and CAC registry.
3. Initialize the TigerBeetle Chart of Accounts mapped directly to the State's Consolidated Revenue Fund.

## Days 61–90: Live Pilot Deployment & First Revenue Split

1. Deploy Wave-0 flagship edge hardware (weighbridges / rugged Android POS / ANPR cameras).
2. Onboard initial field enforcement officers; register the first 10,000 taxpayers / operators.
3. Execute the first live end-to-end transaction with instant, automated statutory revenue split to the TSA.

## Boardroom Action Sheet — Day-1 Sign-Offs

1. **Concession Approval** — approve the Zero-CapEx Turnkey Technology PPP Concession Agreement under the State PPP Law / ICRC guidelines.
2. **Statutory Split Order** — authorize the Ministry of Finance to gazette the automated revenue-split schedule (CRF, MDA retention, PPP concessionaire).
3. **Inter-Agency Mandate** — Executive Order mandating all MDAs to federate data registries (Internal Revenue, Lands, Mining, Transport, Health) into the SOS.
4. **Project Steering Team** — appoint the State PMO Lead (Commissioner of Finance or Special Adviser on IGR/Tech) for the 90-day Wave-0 deployment.
